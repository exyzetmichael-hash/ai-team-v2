# ai-team-v2

Персональная команда ИИ-агентов на базе [Hermes Agent](https://github.com/NousResearch/hermes-agent) v0.19.0.
Каждый агент — отдельная роль со своей личностью, памятью и набором инструментов.

> **Техническим специалистам:** полное описание проекта — архитектура, принятые решения с
> обоснованиями, найденные подводные камни и честный список ограничений — в
> **[`docs/project-overview.md`](docs/project-overview.md)**.

## Принципы

- **Не писать инфраструктуру агентов самому.** Первая версия проекта писалась с нуля и
  провалилась. Здесь берётся зрелый фреймворк, а собственный код — только надстройка:
  персоны, конфиги, хуки, интеграции. Ядро Hermes не патчится, чтобы обновления не ломали систему.
- **Минимум привилегий.** Файловая система только у второго мозга; каждое отступление
  обосновано в конфиге рядом с кодом.
- **Мягкие лимиты вместо жёстких.** Бюджет-хук предупреждает, но архитектурно не может
  заблокировать запрос — решение всегда за владельцем.
- **Молчание — валидный ответ.** Утренняя сводка не приходит, если сказать нечего.
- **Дёшево по умолчанию, дорого точечно.** Дешёвая модель на всех ролях; апгрейд там,
  где цена ошибки высока.
