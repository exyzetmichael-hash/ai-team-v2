# Сторонние скиллы в этом репозитории

Взяты из [rampstackco/claude-skills](https://github.com/rampstackco/claude-skills)
(MIT, копия лицензии — `LICENSE-rampstack`), клон от 2026-08-22.

## Что взято и зачем

Из 103 скиллов каталога поставлено пять. Остальные — про маркетинговые
сайты: SEO, брендинг, лид-магниты, воронки конверсии, платная реклама,
email-рассылки. У веб-интерфейса EDITH нет ни поисковой выдачи, ни
аудитории, ни конверсии: это приватный однопользовательский инструмент за
Tailscale. Ставить туда skill про пСЕО или про архетипы бренда — засорять
индекс скиллов ради никогда не срабатывающих триггеров.

| Скилл | Зачем здесь |
|---|---|
| `design-standards` | Стандарты вёрстки: контраст, отступы, типографика, иерархия. Ровно то, что отличает «работает» от «удобно» |
| `frontend-component-build` | Архитектура компонентов и их состояния (загрузка, ошибка, пусто) — сейчас интерфейс написан одним файлом, при росте это станет больно |
| `accessibility-audit` | WCAG. Не про «инклюзивность вообще», а про вещи, которые Михаил ощутит лично: размеры целей нажатия на телефоне, фокус с клавиатуры, читаемость в темноте |
| `performance-optimization` | Core Web Vitals и скорость отклика. Интерфейс открывается с телефона на ходу |
| `jtbd-framing` | Jobs-to-be-Done — чтобы фичи выбирались по реальной задаче Михаила, а не по списку «что было бы прикольно» |

## Как с ними обращаться

Это инструкции из чужого репозитория. Перед установкой прогонялись на
инъекции (`curl | bash`, «игнорируй предыдущие инструкции», отправка
данных наружу, base64) — чисто. Но при обновлении проверять заново.

Скиллы каталога рассчитаны на публичные коммерческие сайты. Там, где их
советы упираются в «конверсию», «аудиторию» или «SEO», для EDITH это
неприменимо — брать надо инженерную часть, а не маркетинговую рамку.
