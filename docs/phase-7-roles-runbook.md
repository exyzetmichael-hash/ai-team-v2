# Фаза 7 — Runbook: новые роли (финансист, тьютор, трекер, ресёрчер, юрист)

**Цель:** развернуть пять новых профилей. Все пятеро однотипные — лёгкие агенты по образцу секретаря, поэтому здесь один общий шаблон, а не пять отдельных инструкций.

| Профиль | Роль | Особенность конфига |
|---|---|---|
| `finance` | личные деньги: траты, доходы, накопления на переезд | ничего лишнего, считает «в уме» и показывает выкладки |
| `tutor` | самообразование: матан, линал, Python, алгоритмы, ML | **включён `code_execution`** — проверять решения запуском |
| `tracker` | состояние проектов, открытые вопросы, что зависло | чистая память, знает только со слов Михаила |
| `research` | ресёрч по запросу, источники, выжимки | веб-поиск критичен (не отключён) |
| `legal` | договоры, самозанятость/ИП, права на результат, маркетплейсы | веб-поиск критичен + самый высокий риск ошибки |

**Общий принцип:** доступа к файловой системе и vault у них **нет** — это осталось только у `brain` (принцип брифа 3.3). Терминал есть только у секретаря, и то вынужденно, ради Google Calendar.

## 1. Развернуть все пять разом

```bash
cd ~/ai-team-v2 && git pull

# Переиспользуем ключ OpenRouter из уже работающего профиля секретаря —
# отдельный ключ каждому профилю не нужен.
KEY=$(grep '^OPENROUTER_API_KEY=' ~/.hermes/profiles/secretary/.env | cut -d= -f2-)
echo "${KEY:0:12}..."   # проверь, что не пусто и похоже на sk-or-...

for p in finance tutor tracker research legal; do
  hermes profile create "$p"
  cp "profiles/$p/SOUL.md"     ~/.hermes/profiles/$p/SOUL.md
  cp "profiles/$p/config.yaml" ~/.hermes/profiles/$p/config.yaml
  echo "OPENROUTER_API_KEY=$KEY" >> ~/.hermes/profiles/$p/.env
  chmod 600 ~/.hermes/profiles/$p/.env
  mkdir -p ~/.hermes/profiles/$p/plugins
  cp -r plugins/budget-guard ~/.hermes/profiles/$p/plugins/
  hermes -p "$p" plugins enable budget-guard
done
```

⚠️ **Если `hermes profile create` или `plugins enable` начнут задавать вопросы** — цикл на этом встанет и будет ждать ввода. Тогда прогони по одному профилю за раз (те же команды, только без `for`, подставляя имя руками). Я не могу проверить интерактивность этих команд без сервера.

**Проверь, что всё создалось:**
```bash
hermes profile list
```
Должны появиться пять новых профилей рядом с `secretary` и `brain`.

## 2. Живой тест — по одному вопросу на роль

Смысл: убедиться, что каждый отвечает по своей теме и **не лезет в чужую**.

```bash
hermes -p finance
```
```
Записывай: сегодня потратил 450 на еду и 1200 на интернет. Сколько всего?
```
→ должен посчитать, показать выкладку (450 + 1200 = 1650) и запомнить.

```bash
hermes -p tutor
```
```
Объясни, что такое собственные значения матрицы, и дай задачу на проверку.
```
→ объяснение + задача. Попроси решить питоновскую задачку — должен **запустить код**, а не гадать.

```bash
hermes -p tracker
```
```
Работаю над fintracker. Запомни: доделал импорт CSV, открытый вопрос — как хранить категории.
```
→ запомнил. Потом в новой сессии спроси «что там по fintracker» — должен вспомнить открытый вопрос.

```bash
hermes -p research
```
```
Что сейчас с ценами на OpenRouter для deepseek-моделей? Дай ссылки.
```
→ должен **реально сходить в веб** и дать ссылки, а не ответить по памяти.

```bash
hermes -p legal
```
```
Самозанятость или ИП для фриланса на разработке? Какие лимиты сейчас.
```
→ должен проверить актуальные лимиты поиском, дать нормы, и **прямо сказать, что на серьёзных решениях нужен живой юрист**.

## 3. На что смотреть в первую неделю

- **Роли не должны расползаться.** Если финансист начнёт объяснять матан, а тьютор — считать бюджет, значит границы в SOUL сформулированы слабо. Пришли мне пример — поправлю.
- **Тьютор и юрист — главные кандидаты на апгрейд модели.** У обоих цена ошибки высокая (неверное объяснение закрепляется; выдуманная статья закона выглядит убедительно). Заметишь враньё — скажи, поменяем модель в их конфиге, это одна строка.
- **Ресёрчер обязан давать ссылки.** Если отвечает по памяти без поиска — это провал роли, чини сразу.
- **Трекер не должен выдумывать статусы.** Он знает только то, что ты ему сказал. Начнёт сочинять правдоподобное — пришли пример.

## Критерии готовности фазы 7
- [ ] Все пять профилей созданы, отвечают, помнят контекст между сессиями.
- [ ] Каждый держится своей темы и отправляет чужое к нужной роли.
- [ ] `research` и `legal` реально ходят в веб, а не отвечают по памяти.
- [ ] `tutor` проверяет код запуском, а не «на глаз».
- [ ] `budget-guard` стоит на всех пяти (расход виден одинаково по всей команде).
