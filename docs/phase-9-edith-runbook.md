## 6. Google-таблица финансов — создать и подключить

Таблицы ещё нет. Полная структура (7 листов: Операции/Категории/Регулярные платежи/Цели/
Бюджеты/Долги/Сводка с графиками) — собрана по 12 уточняющим вопросам, см.
[`finance-sheet-spec.md`](finance-sheet-spec.md). Не плоский список из 5 колонок — переделывать
структуру задним числом, когда там уже есть данные, дороже, чем спроектировать сразу.

В чате с EDITH одним сообщением:
```
Создай Google-таблицу для учёта моих финансов, семь листов:

1. Операции — журнал: Дата, Тип (Доход/Расход), Категория, Сумма, Комментарий, Источник
   дохода (заполняется только при Тип=Доход: База/Разовое). Тип и Категория — выпадающие
   списки, Категория ссылается на лист "Категории".

2. Категории — справочник для выпадающих списков.
   Расходы: Еда, Транспорт, Аренда, Подписки, Здоровье, Одежда, Развлечения, Образование, Прочее.
   Доходы: База, Фриланс, Подарок, Возврат долга, Прочее.

3. Регулярные платежи — Название, Категория, Сумма, Периодичность, Дата след. платежа,
   Активен, Комментарий.

4. Цели — Цель, Целевая сумма, Собрано, Срок, Прогресс % (формула =Собрано/Целевая сумма),
   Комментарий. Сразу добавь цель: "Переезд в Петербург", срок конец августа 2026.

5. Бюджеты — Категория, Лимит в месяц, Потрачено в этом месяце (формула SUMIFS по листу
   Операции: категория + текущий месяц), Остаток, % использовано.

6. Долги — Кто/Кому, Направление (Мне должны/Я должен), Сумма, Дата возникновения,
   Срок возврата, Статус (Открыт/Закрыт), Комментарий.

7. Сводка — дашборд: остаток за текущий месяц (формула), круговая диаграмма расходов по
   категориям за текущий месяц, линейный график баланса нарастающим итогом, прогресс по
   целям, ближайшие регулярные платежи (в течение недели), сумма открытых долгов.

Пришли ссылку.
```

Формулы и графики EDITH может доводить в 2-3 приёма диалога — это нормально, не блокер.
Открой ссылку, проверь все семь листов и что графики на `Сводка` реально построились.
Держи эту вкладку в закладках браузера/телефона — это и есть «панель для взгляда без
запроса», см. п.9 в спеке (плюс раз в неделю EDITH будет присылать сводку сама — это
отдельная cron-задача, настраивается на шаге 9 ниже).

**Проверка записи:**
```
Запиши трату: сегодня, 500 рублей, еда, обед в кафе.
```
Открой лист `Операции` — строка должна появиться, и цифра в `Бюджеты`/`Сводка` — обновиться.

## 6.1. Голосовые сообщения в Telegram

Автотранскрипция уже встроена в гейтвей — специально звать инструмент не нужно, входящее
аудио расшифровывается само и подставляется в сообщение как обычный текст, до того как его
увидит модель. Настроить нужно только провайдера речи-в-текст.

Провайдер — **Groq** (`whisper-large-v3-turbo`): бесплатный тариф без карты (2000
запросов/день, для одного человека с огромным запасом), не грузит CPU/RAM сервера, лучше
распознаёт русский, чем локальный вариант на модели `base` (сервер и локальный потянул бы —
9.9 ГБ свободно, 6 ядер, — но раз бесплатный внешний ещё и качественнее, смысла в локальном
нет). ⚠️ У Groq в этой версии Hermes нет параметра языка — распознавание идёт по
автоопределению модели на самом звуке (не по тексту), путаницы на коротких голосовых почти
не бывает.

**Ключ:** [console.groq.com](https://console.groq.com) → зарегистрироваться (карта не
нужна) → API Keys → создать ключ.

```bash
echo 'GROQ_API_KEY=<твой ключ>' >> ~/.hermes/profiles/edith/.env
chmod 600 ~/.hermes/profiles/edith/.env

cd ~/ai-team-v2 && git pull
cp profiles/edith/config.yaml ~/.hermes/profiles/edith/config.yaml
```

Перезапусти сессию (`hermes -p edith`, если проверяешь из CLI) или сам Telegram-бот после
шага 10 — и пришли голосовое сообщение в чат. Ответ должен показать, что EDITH поняла
содержание, будто ты написал текстом.
